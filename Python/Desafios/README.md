# Desafios de Python

Trilha de exercicios progressivos para treinar logica de programacao,
do zero ate conceitos avancados. Cada arquivo tem um enunciado (no
docstring) e um esqueleto com `# TODO` para voce completar.

## Como usar

1. Abra o arquivo do desafio no VS Code.
2. Leia o enunciado no topo (docstring).
3. Apague os `pass` e implemente a logica onde ha `# TODO`.
4. Rode o arquivo com `Ctrl+F5` ou `python nome_do_arquivo.py` no terminal.
5. Alguns arquivos tem linhas de `assert` comentadas no final: descomente
   para validar sua solucao automaticamente (se nao der erro, passou).

Nao existe gabarito nos arquivos de proposito: o objetivo e voce
raciocinar e so pesquisar quando estiver realmente travado. Depois
de resolver, vale comparar sua solucao com implementacoes dos repos
listados abaixo para ver outras formas de pensar.

## Estrutura

- `01-Basico/` — variaveis, condicionais, loops, funcoes, strings,
  listas simples. Ideal pra quem esta comecando agora.
- `02-Intermediario/` — dicionarios, arquivos (txt/JSON), excecoes,
  POO basica, algoritmos simples de busca/ordenacao.
- `03-Avancado/` — decorators, generators, recursao mais complexa,
  estruturas de dados do zero (pilha, fila, arvore), algoritmos de
  ordenacao classicos, consumo de API, testes automatizados, SQLite
  e um projeto final que junta tudo.

## Repositorios do GitHub para continuar praticando

Depois de passar pelos 30 desafios, esses repositorios tem uma
quantidade enorme de exercicios e codigo real pra ler, copiar e
treinar musculatura de programacao:

| Repositorio | Nivel | Por que usar |
|---|---|---|
| [Asabeneh/30-Days-Of-Python](https://github.com/Asabeneh/30-Days-Of-Python) | Basico -> Avancado | Curso completo em 30 dias, do zero ate web scraping, APIs e MongoDB. Muito didatico e com exercicios em cada topico. |
| [zhiwehu/Python-programming-exercises](https://github.com/zhiwehu/Python-programming-exercises) | Basico -> Avancado | Mais de 100 exercicios classificados por dificuldade (nivel 1, 2 e 3), com dicas e solucoes. Otimo para treinar logica pura. |
| [TheAlgorithms/Python](https://github.com/TheAlgorithms/Python) | Intermediario -> Avancado | Mais de 1000 algoritmos implementados em Python (ordenacao, busca, grafos, programacao dinamica, etc). Leia o codigo e tente reimplementar sem olhar. |
| [prabhupant/python-ds](https://github.com/prabhupant/python-ds) | Intermediario -> Avancado | Estruturas de dados e algoritmos focados em preparacao para entrevistas tecnicas (LeetCode/HackerRank style). |
| [geekcomputers/Python](https://github.com/geekcomputers/Python) | Basico -> Intermediario | Centenas de scripts pequenos e praticos (automacao, manipulacao de arquivos, utilitarios). Bom pra copiar codigo real e entender na pratica. |
| [practical-tutorials/project-based-learning](https://github.com/practical-tutorials/project-based-learning) | Intermediario -> Avancado | Lista de tutoriais passo a passo para construir projetos reais (tem uma secao so de Python). Bom depois de dominar o basico, pra sair do exercicio isolado e construir algo maior. |

### Sugestao de fluxo de estudo

1. Termine `01-Basico/` e `02-Intermediario/` aqui.
2. Va para o **zhiwehu/Python-programming-exercises** pra consolidar
   logica com mais volume de exercicios curtos.
3. Termine `03-Avancado/` aqui.
4. Va para o **TheAlgorithms/Python** e o **prabhupant/python-ds**
   pra estudar algoritmos e estruturas de dados mais a fundo (bom
   inclusive se um dia quiser entrevistas tecnicas).
5. Escolha 1-2 projetos do **practical-tutorials/project-based-learning**
   pra sair do exercicio e construir algo completo do zero.
